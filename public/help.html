Help & Documentation

Complete A-Z guide for CJ Product Hunter — web app & Chrome extension.

🚀 Getting Started

  1. Sign up / Sign in — Create an account or sign in at cj-winning-product-hunter-poc.vercel.app
  2. Add your CJ API Key — Click ⚙ Settings → Paste your CJdropshipping API Key (from My CJ → API in your CJ account)
  3. Start hunting — Search products, use Trending Winners, or Best-Selling modes

Note: Each user uses their own CJ API key. Keys are encrypted on our server and never shared.

🧩 Chrome Extension

Installation

  1. Download cj-product-hunter-extension.zip from the repository
  2. Open chrome://extensions → Enable "Developer mode"
  3. Click "Load unpacked" → Select the extracted extension/ folder
  4. Click the extension icon → Sign in with your account → Enter your CJ API Key

Features

  • Side Panel — Stays open while you browse CJ (click extension icon)
  • Popup — Quick search from toolbar
  • Always-on Window — "Open as always-on window" button for detached panel
  • Dark/Light mode — 🌙 toggle in header

⚙ Filters

Basic Filters

  • Price range — Min/Max CJ cost (USD)
  • Stock range — Min/Max available inventory
  • Sellers (listed by) — Min/Max number of sellers who listed this product
  • Country / Warehouse — Filter by ship-from warehouse (CN, US, TH, etc.)
  • Deliver to — Destination country for shipping estimates
  • Free shipping — Only products with free shipping
  • Quick delivery — Stock available in destination warehouse

Listing Age Filters (require enrichment)

  • 🆕 New listing — Listed on CJ ≤ 7 days ago
  • ✨ New product — Listed on CJ ≤ 30 days ago
  • ♻ Re-listing — Was inactive, now active again
  • 🚫 Never listed — 0 sellers have listed this product
  • Max days since listed — Only show products ≤ N days old

📦 Product Cards — What You See

  • CJ Cost / Promo Price — Your cost from CJ
  • 🏪 Sellers — Number of sellers who listed this product
  • Stock — Available inventory
  • 🚀 Delivery — Estimated days / Quick delivery badge
  • 📅 Listed age — Days since first listed on CJ
  • Supplier — Vendor name (click "Supplier info" for details)
  • Score — Winning score (0-100) with label
  • 💰 Est. Revenue / ✅ Est. Profit / 📈 Margin — Profit estimation (see Profit Calculation)
  • 📊 View analysis → — Full detail modal with sales, reviews, supplier, logistics
  • 📅 Listing age → — Focused modal with listing date details
  • 🏪 List to CJ — One-click listing to your CJ store

💰 Profit / Loss Estimation

Each product card shows a profit section when data is available:

💰 Est. revenue $X,XXX.XX
✅ Est. profit $X,XXX.XX
📈 XX% margin

Formula

  • Revenue = Suggested Sell Price × Monthly Estimated Sales (dailyEst × 30) or Total Sales or 100
  • Gross Profit = Revenue − (CJ Cost × Quantity)
  • Net Profit = Gross Profit − $5 Shipping − Platform Fee (15% of Revenue)
  • Margin % = (Net Profit / Revenue) × 100

Margin Color Coding

  • 🟢 Green (>30%) — Excellent margin
  • 🟠 Orange (15-30%) — Moderate margin
  • 🔴 Red (<15%) — Low margin, review carefully

* Estimates based on CJ sales data (90-day sales, order count). Actual results vary by marketing, competition, returns, etc.

🏆 Best Sellers — Supplier Analysis

Click 🏆 Best Sellers → Enter keyword → Select ship-to country → Search

What you get

  • Suppliers ranked by total sales (7d/30d/90d toggle)
  • Country filter — Only suppliers with stock in selected warehouse
  • Expandable supplier rows → Top 5 products with sales, profit, listing age
  • Click product → Full detail modal

📊 View Analysis — Detail Modal

Click 📊 View analysis → on any product card for:

  • Product info — SKU, images, variants, category
  • Pricing — CJ cost, suggested retail, margin estimate
  • Supplier — Name, website, email, phone, warehouse countries
  • Sales — Total CJ orders, 7d/30d/90d estimates, last order date
  • Reviews — Total, average rating, recent breakdown
  • Logistics — Sellers count, free shipping, stock by country
  • Listing age — Exact first-listed date, days ago
  • List to CJ — Variant pricing, shipping quotes, one-click publish

📅 Listing Age Modal

Click 📅 Listing age → for a focused view:

  • First listed date (from CJ createrTime field)
  • Days since listing (human-readable: "X days ago" / "X months ago" / "X years ago")
  • Listing status badges (🆕 New ≤7d, ✨ New ≤30d, ♻ Re-listing)
  • Data source indicator (CJ productDetail vs enrich API)

📄 Pagination

  • Web app — 20 products/page, Prev/Next buttons
  • Extension — 50 products/page, Prev/Next buttons
  • Page number shown as "Page X of Y"

🌙 Dark / Light Mode

  • Toggle in top bar (web app, popup, side panel)

👑 Admin Panel

Access at /admin (requires is_admin=true in Supabase profiles table)

Active Users Widget

  • 🟢 Online now — Heartbeat in last 5 minutes
  • Total registered — All users
  • Active (24h) — Users with heartbeat in last 24 hours

Two-Card Layout

  • Left: Active Users (green dot = online)
  • Right: All Registered Users

User Management

  • Block / Unblock user
  • Set daily / monthly API limits
  • Device block / unblock
  • Password reset
  • Delete CJ API key
  • Usage logs & audit log

📊 API Limits & Usage

  • Each user has daily/monthly limits (set by admin)
  • Current usage shown in Settings modal
  • Resets at 00:00 UTC (daily) / 1st of month (monthly)
  • Heartbeat every 60s marks user online

🔧 Troubleshooting

IssueSolution
"CJ API key needed"Paste your CJ API Key in Settings (⚙ Key)
"Server not reachable"Check internet; backend may be cold-starting (wait 10s)
"Daily/Monthly limit reached"Wait for reset or ask admin to increase limit
"Invalid API key"Re-enter key from My CJ → API; ensure no extra spaces
No products foundLoosen filters (price, stock, sellers, listing age)

🔒 Privacy & Security

  • Your CJ API Key is encrypted (AES-256-GCM) on our server
  • Extension never stores your API key locally
  • Passwords hashed with bcrypt (Supabase Auth)
  • No analytics, no tracking, no third-party scripts
  • Open source — audit the code

⌨ Keyboard Shortcuts

  • Escape — Close any modal
  • Ctrl/Cmd + K — Focus search (web app)
