📋 How to get your CJ API Key:
  1. Log in to https://www.cjdropshipping.com
  2. Go to My CJ → API (or Integrations → API App)
  3. If needed, click Enable on the API App
  4. Click Generate and copy your API key
  5. Paste it here — it looks like xxx@api@yyy

Your key is encrypted and stored securely.
